# Task Workbooks

Each workbook is the plan and verification record for one product task. It is updated immediately before implementation so assumptions become explicit and testable.

## Planning gate

A workbook is ready for implementation only when it contains:

- a fixed objective and non-goals;
- dependencies and architecture decisions;
- concrete deliverables and expected file areas;
- data/security implications;
- acceptance criteria;
- verification commands and browser scenarios;
- risks, fallbacks, and rollback notes.

During implementation, findings from live product validation are recorded in the active workbook. On completion, the result and verification evidence are added before the task is marked complete in `tasks.md`.
